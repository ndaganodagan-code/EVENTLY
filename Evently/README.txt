EVENTLY UGANDA - website files
==============================

Live preview: https://claude.ai/artifact/768W5B3G3JsBMUaS91ty2U

Open the site:   double-click index.html (works offline in Chrome or Edge;
                 the QR codes on posters need an internet connection).

What's in here
  index.html            the page (styles, header, footer)
  data.js               all event listings, deals, venues, ticket links
  core.js               shared logic (dates, countdowns, posters, storage)
  pages1.js             home, discover, event pages, weekend, trending
  pages2.js             near me, deals, sign-in, my events, gallery, poster maker
  pages3.js             organizer dashboard, admin, about/contact/help pages
  posters\              real event posters (one per event, named by event)
  logo-*.png, favicon   logo files used on the site
  brand\                full logo files
  download-posters.ps1  script that downloads posters for new events

Notes
  - Evently does not sell tickets. "Buy tickets" buttons open the seller's site.
  - Accounts, saves and submissions are stored in your own browser for now.
    The first account created in a browser becomes admin.
  - Past events disappear from listings one day after they end.
  - New events are added every Monday morning (Kampala time) to the live preview.
